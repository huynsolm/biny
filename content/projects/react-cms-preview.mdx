## 문제

CMS 컴포넌트는 타입이 많아서, 제목이나 내용을 바꿀 때마다 HTML 소스를 직접 고치고 화면을 확인하는 일이 반복됐어요.

## 역할

React 기반으로 만든 CMS 컴포넌트 도구에서 타입 01부터 26까지를 고도화하는 작업을 했어요.

## 구현

- 텍스트를 입력하면 해당 컴포넌트의 HTML 소스가 만들어지고, 결과 화면을 같이 미리 볼 수 있는 흐름을 구현했어요.
- 컴포넌트 타입을 골라 같은 화면에서 확인할 수 있게 했어요.

## 확인할 수 있는 것

이 도구는 내부 운영 흐름과 맞닿아 있어서 공개 화면과 소스는 연결하지 않아요. 화면 캡처도 아직 공개 범위를 정하지 못해서 싣지 않았어요.

성과 수치는 적지 않아요.

## 이 경험이 프론트엔드로 이어지는 지점

입력값이 바뀌면 결과 화면이 따라 바뀌는 구조는 상태에서 화면을 만드는 React의 기본 흐름이에요. Next.js와 TypeScript는 학습하고 문서로 정리한 단계라서, 이 도구에 쓴 기술로 적지 않아요.
