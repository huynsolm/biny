## 문제

CMS 컴포넌트는 타입이 여러 개라서, 내용을 바꿀 때 결과 HTML 소스와 화면을 함께 확인할 수 있는 흐름이 필요했습니다.

## 역할

근무 시간 외에 직접 만들어 본 개인 프로젝트입니다. React 기반 CMS 컴포넌트 도구에서 타입 01부터 26까지의 고도화 작업을 맡았어요.

## 구현

- 텍스트를 입력하면 컴포넌트의 HTML 소스가 만들어지고, 결과 화면을 함께 미리 볼 수 있는 흐름을 구현했습니다.
- 컴포넌트 타입을 골라 같은 화면에서 확인할 수 있어요.

## 확인할 수 있는 것

원본 화면과 소스는 공개용으로 정리하지 않아 링크하지 않습니다. 대신 [데모 열어 보기](/cms-preview)에서, 원본 도구의 타입 25개(01~07, 09~26)를 샘플 데이터로 다시 만든 버전을 눌러 볼 수 있어요. 만들어지는 HTML은 원본 도구와 같은 클래스 이름과 구조를 씁니다. 원본의 DB 연결, 메뉴 관리자, 이미지 업로드는 옮기지 않았어요.

## 이 경험이 프론트엔드로 이어지는 지점

입력값이 바뀌면 결과 화면이 따라 바뀌는 구조는 상태에서 화면을 만드는 React의 기본 흐름과 같습니다. Next.js와 TypeScript는 학습하고 문서로 정리한 단계라서, 이 도구에 쓴 기술로는 적지 않았어요.
