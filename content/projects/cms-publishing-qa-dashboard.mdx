## 문제

제가 일할 때 지키는 점검 기준(시맨틱 마크업, 반응형, 키보드, 브라우저, 발행)을 글로만 적는 데서 멈추지 않고, 동작하는 화면으로 만들어 보고 싶었어요. 개인 학습 목적의 데모예요.

## 역할

기획부터 구현까지 혼자 맡은 별도 개인 프로젝트예요. 실제 업무에 쓰인 도구가 아니고, 샘플 데이터만 써요.

## 구현

- 페이지를 샘플로 등록하고, 항목마다 미점검, 통과, 실패, 해당 없음으로 상태를 기록해요. 모든 항목이 통과나 해당 없음일 때만 발행 가능으로 보여 줘요.
- 상태 변경, 요약, 발행 가능 판정, 저장값 검증은 화면과 분리한 순수 함수로 만들고 Vitest로 테스트했어요.
- 저장은 브라우저 localStorage만 써요. 저장값이 깨졌거나 직접 고쳐졌으면 샘플로 시작하고, 저장이 막힌 환경에서도 화면은 그대로 동작해요.
- 네이티브 select와 레이블로 만들었고, 터치 영역은 44px 이상으로 두었어요. 삭제와 되돌리기는 같은 화면의 확인 단계를 거쳐요.

[데모 열어 보기](/qa-dashboard)에서 직접 눌러 볼 수 있어요. 별도 개인 프로젝트이고 샘플 데이터만 써요.
