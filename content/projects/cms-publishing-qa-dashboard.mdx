## 문제

제가 일할 때 지키는 점검 기준(시맨틱 마크업, 반응형, 키보드, 브라우저, 발행)을 글로만 적는 데서 멈추지 않고, 동작하는 화면으로 만들어 보고 싶었습니다.

## 역할

기획부터 구현까지 혼자 맡았고, 화면의 데이터는 모두 샘플입니다.

## 구현

- 페이지를 샘플로 등록하고 항목마다 미점검, 통과, 실패, 해당 없음을 기록합니다. 모든 항목이 통과나 해당 없음일 때만 발행 가능으로 표시해요.
- 상태 변경, 요약, 발행 가능 판정, 저장값 검증은 화면과 분리한 순수 함수로 만들고 Vitest로 테스트했습니다.
- 저장은 브라우저 localStorage만 씁니다. 저장값이 깨졌거나 직접 고쳐졌으면 샘플로 시작하고, 저장이 막힌 환경에서도 화면은 그대로 동작해요.
- 네이티브 select와 레이블로 만들고 터치 영역은 44px 이상으로 두었습니다. 삭제와 되돌리기는 같은 화면에서 확인 단계를 거쳐요.
