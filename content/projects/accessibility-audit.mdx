## 문제

마크업을 만들면서 자주 확인하는 접근성 항목을, 브라우저에서 HTML을 붙여 넣는 것만으로 바로 점검할 수 있으면 좋겠다고 생각했습니다.

## 역할

기획부터 구현까지 혼자 맡았어요.

## 구현

- HTML을 붙여 넣으면 규칙에 따라 점검하고, 결과를 한국어 보고서로 보여 줍니다.
- 문서 언어, 페이지 제목, h1 개수, 이미지 `alt`, 폼 레이블, 링크 텍스트, 제목 단계 건너뛰기를 점검해요.
- iframe의 `title`, 데이터 표의 캡션이나 `aria-label`, 버튼의 접근 가능한 이름, 초점을 받을 수 있는 요소의 `aria-hidden` 사용도 확인합니다.
- 같은 HTML이면 항상 같은 결과가 나오는 규칙 기반 점검이에요.
- 범위는 붙여 넣은 HTML뿐이고, URL 크롤링, API, 서버, 데이터베이스는 쓰지 않습니다.

## 확인할 수 있는 것

위의 데모에서 직접 눌러 볼 수 있고, 소스는 저장소에서 볼 수 있어요. 테스트(Node 내장 테스트 러너)와 GitHub Actions 검증 설정도 저장소에 들어 있습니다. 점검하는 규칙은 위에 적은 항목뿐이라, 접근성 기준 전체를 다루지는 않아요.
