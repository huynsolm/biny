## 문제

병원 홈페이지는 비슷한 구조가 반복됩니다. 사이트마다 공통 마크업과 스타일을 따로 관리하면 제작 과정의 일관성이 떨어질 수 있었어요.

## 역할

반응형 스킨의 HTML 구조화, SCSS 구조 설계, 반응형 UI 구현을 맡았습니다.

## 구현

- 반응형 스킨의 공통 마크업과 SCSS 구조를 정리하고, 공통 구조와 스킨별 스타일을 분리했습니다.
- `gulp-nunjucks-render`를 검토한 끝에 `gulp-file-include` 기반 템플릿으로 전환하고 고도화했어요.
- 변수, 반복문, include로 HTML을 컴포넌트처럼 나눠 GNB, 사이트맵, 버튼, 슬라이더 같은 반복 UI를 재사용할 수 있게 했습니다.
- SCSS 표준화, 폴더와 파일 이름 정리, Swiper의 `data-*` 속성 기반 관리도 함께 진행했어요.
- SKIN01부터 SKIN08까지를 한 제작 환경에서 다루도록 고도화했습니다.
- 작업 내용은 Confluence와 GitLab에 문서로 남겼어요.

## 확인할 수 있는 것

공개 데모에서 8개 스킨을 직접 볼 수 있고, 소스 기록은 GitHub 저장소에서 볼 수 있습니다. 시간 단축률이나 오류 감소율 같은 수치는 검증된 기준이 없어 싣지 않았고, 내부 문서 화면과 비공개 운영 정보는 공개하지 않습니다.

## 이 경험이 프론트엔드로 이어지는 지점

공통 UI와 변형 UI를 나누는 발상은 컴포넌트 설계와 같은 문제입니다. 다만 이 프로젝트는 SCSS와 Gulp 기반이라, React나 TypeScript 경험으로 내세우지는 않아요.
