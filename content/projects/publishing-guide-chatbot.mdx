## 문제

접근성 규칙과 퍼블리싱 기준을 반복해서 찾아보고 설명해야 했어요.

## 역할

기획부터 구현까지 맡은 개인 프로젝트예요. 아직 계속 만들고 있는 MVP예요.

## 구현

- 웹 접근성 규칙을 설명하는 공개 홈페이지들에서 내용을 추출해 마크다운 문서로 정리했어요. 직접 정리한 CSS 분석도 근거 문서에 함께 있어요.
- 질문하면 근거 문서를 먼저 검색하고, 찾은 내용을 바탕으로 답하게 했어요. 지어낸 답을 줄이려는 의도예요.
- 가이드 질문, 코드 검사, 체크리스트, 기준 소스(복사해서 쓸 수 있는 HTML, SCSS, JS 예시), 사용법을 한 화면의 탭으로 묶었어요.
- 문장보다 핵심어로 검색하면 더 잘 찾는다는 안내와 질문 예시를 화면에 넣었어요.

## 확인할 수 있는 것

위의 데모에서 직접 질문해 볼 수 있어요.

지어낸 답을 줄이려는 시도이고, 정확도를 수치로 재지는 않았어요. 별도 개인 프로젝트이고, 실제 업무에 쓰이는 도구는 아니에요.
