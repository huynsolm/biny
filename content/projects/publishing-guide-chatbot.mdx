## 문제

접근성 규칙과 퍼블리싱 기준을 반복해서 찾아보고 설명해야 했어요.

## 역할

기획부터 구현까지 맡았고, 아직 MVP 단계입니다.

## 구현

- 근거 문서는 웹 접근성 규칙을 설명하는 공개 자료에서 추출해 마크다운으로 정리했습니다. W3C WAI의 WCAG 2.2 Quick Reference, WAI-ARIA Authoring Practices Guide, MDN Web Docs, web.dev, NHN TOAST UI 프런트엔드 가이드, GOV.UK Design System, GitHub Primer, TOAST UI Components, NAVER egjs를 참고했고, 직접 정리한 CSS 분석도 함께 있어요.
- 외부 문서를 그대로 붙여 넣지 않고, 프로젝트에서 바로 판단할 수 있는 규칙(체크리스트, 좋은 예와 나쁜 예)으로 다시 정리하는 방식으로 쌓고 있습니다. 접근성 기준은 WCAG 2.2 AA를 목표로 두었어요.
- 질문의 핵심어로 근거 문서를 먼저 찾고, 찾은 내용을 요약과 체크 포인트로 정리해 보여 줍니다. 답변 아래에는 출처 문서 이름과 파일명, 매칭된 키워드가 함께 나와요.
- 화면은 가이드 질문, 코드 검사, 체크리스트, 기준 소스(복사해서 쓰는 HTML, SCSS, JS 예시), 사용법 탭으로 나눴습니다. 핵심어로 검색하면 더 잘 찾는다는 안내와 질문 예시도 화면에 있어요.

## 확인할 수 있는 것

위의 데모에서 직접 질문해 볼 수 있어요. 근거 문서에서 관련 내용을 찾지 못하면 "관련 내용을 찾지 못했습니다"라고 안내합니다. 질문의 핵심어가 문서와 맞아야 찾을 수 있고, 문서 범위는 아직 접근성과 퍼블리싱 기준에 한정돼 있어요. 정확도는 수치로 측정하지 않았습니다.
