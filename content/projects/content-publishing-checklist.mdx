## 문제

페이지를 공개하기 전에 확인할 항목을 빠뜨리지 않고, 어떤 페이지가 준비됐는지 한눈에 볼 수 있는 도구가 필요했어요.

## 역할

기획부터 구현까지 혼자 맡았습니다.

## 구현

- 페이지 이름과 주소로 릴리스를 만들며, 마감일과 담당자, 메모는 선택 입력입니다.
- 정해진 점검 8개를 체크하면 준비 상태와 진행률이 나타나고, 준비 중인 것과 준비된 것을 나눠 볼 수 있어요.
- 마감일이 있는 항목을 먼저 보여 주고, 마감이 지났거나 오늘이거나 곧 다가온 경우는 한국어로 표시합니다.
- 데이터는 이 브라우저의 localStorage에만 저장됩니다. 기기를 옮기거나 지우기 전에 JSON 백업을 내려받을 수 있고, 검증을 통과한 백업 파일만 복원해요.
- 외부 의존성, 계정, 서버, 데이터베이스는 쓰지 않았습니다.

## 확인할 수 있는 것

위의 데모에서 직접 눌러 볼 수 있고, 소스는 저장소에서 볼 수 있어요. 테스트(Node 내장 테스트 러너)와 GitHub Actions 검증 설정도 저장소에 들어 있습니다.
